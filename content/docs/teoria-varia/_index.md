## File System ##
Il **file system** è il modo in cui i file e le cartelle sono organizzati all’interno di un computer. Ogni dispositivo ha una cartella radice, cioè la cartella principale da cui parte tutto l'albero delle cartelle.
La struttura può essere rappresentata come un albero:
rami: /usr user (/errico /bianchi dentro) /bin (git, cd, rm dentro) binary files /etc eccetera    
(se è presente / davanti è una cartella, altrimenti è un file)
i rami partono da: computer - router - nuvola (internet) - altro computer.

## Navigazione Ipertestuale ##
La **navigazione ipertestuale** permette di cliccare su una parola, un'immagine o un altro elemento per andare direttamente a un'altra pagina o risorsa. Per esempio, quando clicchiamo su una parola sottolineata e si apre un'altra pagina, stiamo usando un collegamento ipertestuale.

Un **link** è un collegamento che permette di passare da una risorsa a un'altra, possiamo navigare tra pagine web, immagini, documenti, video, altre risorse presenti in rete.

**L'ipertesto** è un insieme di documenti collegati tra loro attraverso dei link. La navigazione non è necessariamente sequenziale: possiamo scegliere noi quale collegamento seguire.

**L'ipermedia** amplia questo concetto perché comprende diversi tipi di contenuti, come testo, immagini, audio, video, animazioni. Questi contenuti sono collegati tra loro e permettono di passare da una risorsa all'altra.

La **multimedialità** consiste nell'utilizzare diversi tipi di contenuti per comunicare un'informazione. Una pagina può contenere contemporaneamente testo, fotografie, video, audio, animazioni.
Rappresenta quindi le informazioni attraverso diversi tipi di contenuti.
I file multimediali, come immagini, audio e video, possono occupare molto spazio, quindi  vengono utilizzati degli **algoritmi di compressione**, che permettono di ridurre le dimensioni dei file e quindi occupare meno memoria. Un esempio è WhatsApp, che spesso comprime le fotografie quando vengono inviate, così occupano meno spazio e vengono trasferite più velocemente.
