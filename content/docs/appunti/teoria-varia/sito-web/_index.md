**`Sito Web`:** insieme di pagine che si riferiscono ad uno stesso ente. Le pagine risiedono su uno o più server “sparsi” su Internet.
* possono essere consultate in modo non sequenziale, grazie all’ipertesto su cui si basa la loro struttura portante.

**`Uniform Resource Locator (URL)`:** percorso (stringa) che individua univocamente una risorsa remota.
* un sito può contenere oggetti multimediali di vario tipo, da scaricare o da visualizzare in rete.
* le pagine sono collegate tra loro tramite i link.

## Sito Web efficace ##

* chiarire senso e obiettivi del sito
* definire il suo target, cioè a che utenti rispondere
* essere originale per distinguersi
* prendere spunto dalla concorrenza per seguire i trend vincenti

## Struttura e stile ##

In base alle mode del momento.  
Bisogna decidere le modalità di erogazione dei contenuti e i canali comunicativi (per trasmettere):

* **`Responsive Web Design (RWD)`:** sito in grado di adattarsi alle dimensioni dello schermo di dispositivi diversi
* **Comunicazione:** poche o troppe info possono indurre l’utente ad abbandonare il sito
* **Prassi:** evitare pagine con immagini di grandi dimensioni oppure molte immagini piccole per ottimizzare i tempi di caricamento.

## Layout di un sito ##

4 macroaree per ogni pagina:
* **`Header` (intestazione):** sezione orizzontale in testa alla pagina
* **`Banner`:** spesso un `carousel`, contiene elementi grafici e scorrimento, ma può essere anche una `hero image`
* **`Contenuti`:** ciò che vuole mostrare la pagina corrente
* **`Footer`**
* **`Area riservata`:** `database` e `server` che richiede l'accesso → insieme di pagine e utenti (`client` e `server`)

## Strumenti per realizzare pagine web ##

* un **`PC`**: la maggior parte dello sviluppo (anche web) avviene in locale
* un **`web server`** su cui poter trasferire le pagine web realizzate
* **`Connessione`**: per poter effettuare `upload` e `download` di file e per poter aggiornare globalmente un sito

## WEB EDITOR E ALTRI STRUMENTI SOFTWARE ##

Sono strumenti che permettono di modificare i file che compongono le pagine web, possono essere:
* **`Web editor non visuali`:** orientati alla scrittura del codice, che viene scritto manualmente dagli sviluppatori
* **`Web editor visuali`:** generano automaticamente il codice delle pagine web e utilizzano l’interfaccia visuale

## Content Management System (CMS) ##

È un software che si serve di un `web server` per permettere agli utenti di creare un sito Web con strumenti visuali.

→ **La differenza con un `Web editor`:**
* L’organizzazione dei contenuti del sito
* La manutenzione del sito
* Il controllo sugli accessi degli utenti
* L’aggiunta di funzionalità

→ Suggerisce la praticità con un programma di grafica per creare contenuti visivi adatti al Web prestando attenzione alla dimensione delle immagini.  
→ Viene utilizzato un programma `Client`/`server` di trasferimento di file che segue il protocollo **`File Transfer Protocol (FTP)`**.
